# 证据使用

区分设计要求、上游文档声明、集成测试和生产测量；来源范围见[生态证据台账](../../codespec/design/ecosystem-integration.md)。知识地图与静态质量检查不能证明浏览器、隔离、存储或故障恢复已可用。

[CS10 成熟度分析](../../codespec/decisions/compute-storage-selection.md)区分上游生产证据和本项目组合验收；[Agentic 场景审视 SC01](../../codespec/requirements/agentic-scenarios-and-gaps.md)固定 superpod 证据版本，区分“设计覆盖”与“功能实现”。
